# CareAtlas — Product Vision

## Mission
Reduce administrative burden in Australian general practice, improve clinical data quality, and support safer practice systems — without requiring migration from existing clinical software.

## Principle
**Document once. Complete the work. Measure the outcome. Improve the system.**

## Position
CareAtlas sits alongside Best Practice and MedicalDirector. It does not replace the clinical record. It adds an intelligence and workflow layer above it.

## Modules

| Module | Purpose | Status |
|--------|---------|--------|
| CareAtlas Connect | Patient engagement, booking, communication | Proposed |
| CareAtlas Copilot | AI assistant, document generation, slash commands | In Development |
| CareAtlas Clinical Utility | Coding, recalls, medication reconciliation | Proposed |
| CareAtlas QualityOS | Practice quality improvement, PDSA cycles | Proposed |
| CareAtlas Learn | CPD capture from clinical work | Proposed |
| CareAtlas Intelligence | Population health, practice analytics | Proposed |
| CareAtlas Community | Neighbourhood health, referral network | Proposed |

## Boundaries
- CareAtlas never stores identifiable patient data without an approved security architecture.
- CareAtlas never signs a clinical document automatically.
- CareAtlas never claims MBS eligibility without clinician confirmation.
- CareAtlas never invents clinical evidence.
- All prototype content uses fictional patients and simulated responses.
